<decisions>
## Implementation Decisions

### 1. Candidate Ranking & Real PISA Interfaces (Plan 03.2-03)
- **D-01: Assembly-Aware Candidate Scoring**: Completely eliminate the hardcoded `known_benchmarks` dictionary and static `w_pisa = 3.0` assignment in `quaternary/session.py`. Implement hierarchical biological scoring balancing sequence coverage, experimental resolution, and macromolecular assembly subunit count match. Explicitly penalize isolated domain fragments (e.g. `1DK7` for GroEL) and prioritize full-length multimers (e.g. `1OEL`, `1AON`).
- **D-02: Real Non-Zero Biophysical Interfaces & Transparent N/A**: Extract actual interface parameters (buried surface area in $\text{Å}^2$, solvation energy gain $\Delta^i G$, H-bonds, salt bridges, contacting residues) from PISA for characterized complexes. If PISA calculation is unperformed or unavailable, return explicit status (`UNAVAILABLE` / `NOT_CALCULATED`) and display transparent `N/A` with biological rationale rather than deceptive `0.0` or empty tables.
- **D-03: Multi-Factor Thermodynamic Evaluation & Verification Test**: In Stage 3, assess PISA stability using both dissociation free energy ($\Delta G_{\text{diss}}$) and solvation free energy gain ($\Delta^i G$), categorizing thermodynamic states into `STABLE`, `INTERMEDIATE`, `DISSOCIATED`, with explicit conflict rationale when crystal packing differs from the deposited biological assembly. Verify that real characterized complexes yield non-zero values and create dedicated deterministic tests verifying non-zero extraction.
- **D-04: GroEL Biological Grounding**: Model GroEL (`P0A6F5`) self-assembly strictly as an $A_{14}$ homo-tetradecamer (two back-to-back heptameric rings). Delineate the GroEL-GroES $A_{14}B_7$ complex strictly under `functional_complexes` via Complex Portal / UniProt partner annotations. Eliminate all descriptions of GroEL alone as an $A_{14}B_7$ heterotetradecamer.

### 2. AlphaFold DB / ESMFold Grounding & Multimer Status (Plans 03.2-03 & 03.2-04)
- **D-05: AlphaFold DB Monomer Boundary**: Query `https://alphafold.ebi.ac.uk/api/prediction/{uniprot_id}` (learning from `Structure_Prediction.ipynb`), extract model metadata (`pdb_url`, `cif_url`, `pae_doc_url`) and global mean pLDDT, while strictly enforcing `monomer_context_only = True` and `asserts_oligomeric_state = False`.
- **D-06: No Extra External API Servers**: Do not integrate external ESM Atlas API servers (`api.esmatlas.com`). Stick strictly to the existing server integrations and established offline fixtures/fallbacks already in place.
- **D-07: Monomer Confidence Disclaimer**: In `render_quaternary_summary_card` and `render_evidence_coverage_dashboard`, explicitly label AlphaFold DB metrics as `Monomer Fold Confidence (pLDDT: XX.X)` with an explicit disclaimer: `Monomer tertiary fold confidence only — does not validate quaternary multimeric assembly.`
- **D-08: Honest AlphaFold-Multimer Unconfigured Representation**: Format AlphaFold-Multimer across all UI summary cards and audit dashboards as:
  ```text
  AlphaFold-Multimer
  Status: NOT EXECUTED
  Reason: External prediction runner not configured
  ```
  Styled with a neutral slate/blue badge, distinguishing it cleanly from query failures or network errors.

### 3. Bio-Mechanistic Functional Inference & Uncertainty Schema (Plans 03.2-03 & 03.2-04)
- **D-09: Dedicated 5-Field Functional Inference Breakdown**: Structure `InferredFunction` and `render_functional_inference_card` with explicit, segregated sections:
  1. `Observed Function`: Documented from experimental UniProt comments and validated GO annotations.
  2. `Predicted Function`: Inferred from structural homology or domain matches.
  3. `Quaternary-Mechanism Hypothesis`: Explicit bio-mechanistic hypothesis (e.g. allosteric cooperativity, enclosed folding cavity, zinc-hexamer storage).
  4. `Confidence`: Display the confidence score/value directly without artificial categorical grouping.
  5. `Evidence Supporting Hypothesis`: Provenance basis citing experimental and homology evidence.
- **D-10: Standardized Six-Tier Consensus Vocabulary**: Standardize quaternary consensus statuses across all models and displays:
  - `CONFIRMED`: Multi-source concordant experimental evidence.
  - `SUPPORTED`: Experimental and homology concordant.
  - `CONFLICTING`: Deposited assembly conflicts with PISA thermodynamics or lattice artifacts.
  - `INSUFFICIENT EVIDENCE`: Novel/orphan sequence lacking structural homolog.
  - `UNAVAILABLE`: Query could not be resolved.
  - `PREDICTED`: Inferred strictly from predictive models.
- **D-11: Nuanced Evidence Coverage Query State Enum**: Distinguish detailed query states across the audit dashboard:
  - `QUERY_SUCCESS_WITH_HIT`
  - `QUERY_SUCCESS_NO_HIT`
  - `QUERY_FAILED`
  - `NOT_QUERIED`
  - `UNAVAILABLE`
  - `SKIPPED`
  - `PREDICTION_NOT_EXECUTED` (used for unconfigured AlphaFold-Multimer).
- **D-12: Honest Unknown Representation for Uncharacterized & Novel Sequences**: For uncharacterized proteins (e.g. `P44101`) or de novo sequences lacking structural templates, output:
  - `Experimental oligomeric state`: `UNKNOWN`
  - `Predicted oligomeric state`: `UNKNOWN`
  - `Fallback representation`: `MONOMER BASELINE`
  - `Overall status`: `INSUFFICIENT EVIDENCE`
  Explicitly state that absence of multimer evidence is not biological proof of monomerism.

### 4. Notebook Modularization, One-by-One Displays & Collapsible Presets (Plan 03.2-05)
- **D-13: Abstract Target Selection Card**: Abstract `panel_html` out of notebook Cell 5 into `quaternary.presentation.render_target_selection_card(target_input, active_preset) -> HTML`. Cell 5 contains zero inline HTML strings, executing only `display(render_target_selection_card(TARGET_PROTEIN, active_preset))` followed by `display(render_validation_status(is_valid, msg))`.
- **D-14: Eliminate Redundant Wave 2 Visual Helpers Cell**: Completely remove the duplicate visual helpers markdown and code cell from Wave 2 in `scripts/build_notebook.py` and `Quaternary_Structure.ipynb`. All visualizers are imported once in Cell 2 and ready for use.
- **D-15: Granular One-by-One Presentation Displays**: In Part 1, replace the monolithic 6-display code cell with 6 separate cells, each rendering a single display card accompanied by dedicated markdown biological interpretation and metric explanations:
  1. Quaternary Summary Card
  2. Macromolecular Component Identity Table
  3. Biophysical Interface Contact Chemistry Table
  4. Dynamic Multi-Assembly Equilibrium Viewer
  5. Bio-Mechanistic Functional Inference Card
  6. Evidence Coverage & Scientific Uncertainty Audit Dashboard
- **D-16: Restored Collapsible `<details>` Preset Comparison Panes**: Embed rich, collapsible `<details><summary><b>Expected Biological Behaviors Across Presets (Click to expand)</b></summary>...</details>` panes under every stage (Stages 1 to 6 in Part 2) and summary card in Part 1, providing comparative analysis across the 4 presets:
  - GroEL ($A_{14}$ homo-tetradecamer chaperonin)
  - Insulin ($A_6$ zinc-stabilized storage hexamer)
  - Uncharacterized protein P44101 ($A_1$ uncharacterized baseline)
  - Novel sequence ($A_1$ monomer baseline with insufficient evidence)
