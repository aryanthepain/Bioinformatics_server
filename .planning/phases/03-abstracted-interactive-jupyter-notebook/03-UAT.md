## 2. Issues Diagnosed and Resolved

1. **Empty Notebook On Disk:**
   - *Problem:* `Quaternary_Structure.ipynb` was generated by `build_notebook.py` without pre-execution, leaving `outputs: []` for all 26 cells.
   - *Fix:* Added `execute_notebook()` step via `nbconvert.preprocessors.ExecutePreprocessor` to `scripts/build_notebook.py` so the notebook is written with complete, rich pre-rendered outputs.

2. **Blank `show_json` Viewer in IDE/VS Code:**
   - *Problem:* The viewer relied entirely on `<script src="https://cdn.jsdelivr.net/.../renderjson.min.js">` with fallback hidden inside `<noscript>`, which modern webviews hide because JS is enabled, but CSP blocks third-party scripts.
   - *Fix:* Replaced empty container with pre-formatted syntax-highlighted JSON inside `<pre>`, which progressively enhances to an interactive collapsible tree when `renderjson` runs.

3. **Stage Metrics Outputting "0":**
   - *Problem:* Cells 16-17 inspected `r2.data.get('assemblies')` and `r3.data.get('interfaces')`, but Stage 2 stored candidates in `rcsb_candidates` and Stage 3 had `homology_models`.
   - *Fix:* Provided cross-stage convenience keys in `r2.data` and `r3.data` so that `Assemblies Found: 5` and `Interfaces Analyzed: 42` accurately reflect the discovered structural data.
