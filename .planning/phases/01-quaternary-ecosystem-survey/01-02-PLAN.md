       - Architecture: Local container / ColabFold command-line runner (Fast MSA via MMseqs2).
       - Caller-Opt-in and Hypothesis Prerequisite per D-06:: A multimer-capable prediction source may be proposed after the AlphaFold DB lookup, but execution is caller-opt-in and requires a partner or self-association hypothesis.

    2. **GalaxyHeteromer (Template-based Multimer Prediction)**:
       - Inputs: Target sequence pair / complexes.
       - Access: Web interface / queue (`http://galaxy.seoklab.org/cgi-bin/submit.cgi?type=HETEROMER`).
       - Classification: `web-only` per D-10:. Lacks stable REST API; manual queue polling required.
       - Limitations: Not recommended for automated batch pipeline execution.
    3. **ClusPro 2.0 (Rigid-Body Protein-Protein Docking)**:
       - Inputs: Two PDB structures/models (Receptor + Ligand).
       - Access: REST API / web queue (`https://cluspro.bu.edu/api/`).
       - Authentication: `authenticated` (Academic registration required) per D-10:.
       - Classification: `authenticated` / `web-only` per D-10:. Useful for tertiary-to-quaternary rigid body assembly validation.
