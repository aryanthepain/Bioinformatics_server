    Implement `BaseBioClient` enforcing D-10, D-11, D-12, D-17:
    - Constructor: `__init__(self, config: QuaternaryConfig, cache: Optional[CacheBackend] = None)`
    - Session setup: Create `requests.Session` with `HTTPAdapter` configured with `urllib3.util.Retry`:
      - `status_forcelist=[429, 502, 503, 504]`
      - `respect_retry_after_header=True`
      - `backoff_factor=config.backoff_factor`
    - Caching wrapper: `get_with_cache(endpoint: str, query_key: str, fetch_fn: Callable) -> Dict[str, Any]` checking `cache.get()` before invoking `fetch_fn`, storing via `cache.set()` on success. If `config.force_refresh` is True, bypass read cache.
    - Fixture fallback: If `config.offline_mode` is True, load pre-recorded responses from `quaternary/fixtures/` matching endpoint/query.
    - Async polling method `poll_async_job(self, status_url: str, timeout_sec: int = 120, poll_interval: float = 2.0) -> Dict[str, Any]`:
      - Execute `session.get(status_url, allow_redirects=False, timeout=config.timeout)` in a loop.
      - **Explicit HTTP 303 check (Roadblock 2)**: If `resp.status_code == 303`, extract `location = resp.headers.get("Location")`. If found, execute `session.get(location, timeout=config.timeout)` and return the JSON result.
      - If `resp.status_code == 200`: inspect response. If `resp.json().get("jobStatus") == "FINISHED"`, return results. Otherwise sleep with exponential backoff (`min(interval * 1.5, 15.0)`).
      - If timeout exceeded, raise `TimeoutError`.
  </action>

    - Integrates with `CacheBackend` and offline fixtures
