  <action>
    Implement pluggable caching supporting both JSON files and SQLite (enforcing D-14, D-15):
    1. `quaternary/cache/base.py`:
       - `CacheBackend(ABC)`:
         - `get(endpoint: str, query_key: str) -> Optional[Dict[str, Any]]`
         - `set(endpoint: str, query_key: str, data: Dict[str, Any]) -> None`
         - `clear() -> None`
         - Helper `_hash_key(endpoint: str, query_key: str) -> str`: returns SHA-256 hash.
    2. `quaternary/cache/json_cache.py`:
       - `JsonDirectoryCache(CacheBackend)`:
         - Creates directory `cache_dir / endpoint` if needed.
         - Saves JSON payload to `<hash>.json`.
         - Reads and returns parsed JSON; returns None on cache miss or corrupted file.
         - `clear()` deletes files in cache directory.
    3. `quaternary/cache/sqlite_cache.py`:
       - `SqliteCache(CacheBackend)`:
         - Connects to SQLite db at `sqlite_db_path`.
         - Schema: `CREATE TABLE IF NOT EXISTS api_cache (cache_key TEXT PRIMARY KEY, endpoint TEXT, query_key TEXT, response_json TEXT, created_at REAL)`.
         - Stores serialized JSON in `response_json`.
         - Reads, deserializes, and returns dict on hit.
         - `clear()` drops/deletes table records.
    4. `quaternary/cache/__init__.py`:
       - `get_cache_backend(config: QuaternaryConfig) -> Optional[CacheBackend]`: factory returning `JsonDirectoryCache` or `SqliteCache` if `config.cache_enabled` is True, else None.
  </action>
