  <action>
    Implement `quaternary/session.py` (`QuaternarySession`):
    - State attributes:
      - `session_id: str`: unique ID generated by engine.
      - `target_input: str`: sequence or UniProt accession.
      - `stages: Dict[int, StageResult]`: accumulated results for stages 1 through 6.
      - `output: Optional[QuaternaryStructureOutput]`: final synthesized object.
    - Implement Step-Wise Stage Execution methods:
      1. `run_stage_1_primary_evidence() -> StageResult`:
         - Calls `UniProtClient.get_subunit_annotations()`, `ComplexPortalClient`, and `RCSBSearchClient`.
         - Graceful fallback (D-05): if a client fails, record error in `provenance`, status `UNAVAILABLE`, continue.
      2. `run_stage_2_experimental_qualification() -> StageResult`:
         - Filters PDB candidates by D-02 coverage tiers:
           - Tier 1: $\ge 90\%$ (High Confidence)
           - Tier 2: $70-89\%$ (Qualifying)
           - Tier 3: $< 70\%$ (Provenance-Only)
         - For qualifying hits, queries `PisaClient.get_assembly_interfaces()`.
         - **D-03 Conflict Retention**: If author biological unit and PISA thermodynamic stability disagree ($\Delta G_{\text{diss}} \le 0$), set `conflict_detected: true`, record both assertions in `ExperimentalConflict`.
         - **D-04 Assembly Candidate Ranking**: Compute $S_{\text{assembly}} = W_{\text{coverage}} + W_{\text{resolution}} + W_{\text{pisa}}$:
           - $W_{\text{coverage}}$: $\ge 90\% \rightarrow 3.0$; $70-89\% \rightarrow 2.0$.
           - $W_{\text{resolution}}$: $< 2.0\text{\AA} \rightarrow 3.0$; $2.0-3.0\text{\AA} \rightarrow 2.0$; $> 3.0\text{\AA} \rightarrow 1.0$.
           - $W_{\text{pisa}}$: $\Delta G_{\text{diss}} > 0 \rightarrow 3.0$; $\le 0 \rightarrow 0.0$.
           - Designate top-scoring candidate as primary; retain others in alternatives.
      3. `run_stage_3_homology_and_partners() -> StageResult`:
         - If experimental evidence is absent/inconclusive, query `SwissModelClient.get_homology_models()` and `IntActClient.get_physical_interactors()`.
      4. `run_stage_4_structural_context() -> StageResult`:
         - Query `AlphaFoldClient.get_structural_context()`.
         - Strictly enforce D-05: record monomeric coordinates and pLDDT as structural context only; set `quaternary_status: uncharacterized`.
      5. `run_stage_5_multimer_hypothesis(enable_multimer: bool = False, hypothesis: Optional[str] = None) -> StageResult`:
         - If `not enable_multimer`: formulate multimer proposal (`multimer_hypothesis_eligible: true`, suggested homomer $A_2/A_4$ or heteromer $AB$ from Stage 3).
         - If `enable_multimer`: execute `MultimerPredictorClient.run_multimer_prediction()` with simulation/dry-run.
      6. `run_stage_6_synthesis() -> QuaternaryStructureOutput`:
         - Synthesizes final assembly determination.
         - Segregates confidence metrics into `ConfidenceProvenance` (D-08).
         - Builds and returns `QuaternaryStructureOutput`.
      7. `to_ui(format: str = "json", **kwargs) -> Any`:
         - Dedicated Stage 7 UI export method.
         - If `format == "json"`: returns `self.output.model_dump_json(indent=2)` (default).
         - If `format == "dict"`: returns `self.output.model_dump()`.
         - If `format == "dataframe"`: converts key tables (candidates, stoichiometry, interface contacts) into pandas DataFrames.
  </action>
