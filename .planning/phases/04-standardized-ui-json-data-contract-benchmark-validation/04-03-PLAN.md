  <name>Implement UI Backend LevelResult Adapter</name>
  <files>

  <action>
    1. Create `quaternary/ui_adapter.py`:
       - Define standalone Pydantic models matching `origin/UI:UI/backend/app/schemas.py`:
         - `Headline`, `Metric`, `EvidenceItem`, `Segment`, `Track`, `TableColumn`, `Table`, `Note`, `Link`, `LevelResult`.
       - Implement `quaternary_to_level_result(output: QuaternaryStructureOutput) -> LevelResult`:
         - `source`: `"live"`
         - `headline`: `Headline(value=assembly_string, label="quaternary assembly")`
         - `summary`: High-level plain language description of the oligomeric state and interface count.
         - `metrics`: Subunit count, stoichiometry formula, PISA interface area ($\text{Å}^2$), and quaternary status.
         - `tracks`: Track with `key="interfaces"`, `label="Interface residues"`, `caption="Quaternary · PISA & RCSB"`, `style="marks"`, `tone="ink"`, with 1-based inclusive residue segments.
         - `tables`: Component identity table and PISA interface contact chemistry table.
         - `notes`: Highlight bio-mechanistic functional hypothesis as `Note(kind="observation", ...)`.
         - `links`: PDB and UniProt links if accessions are resolved.
         - `raw`: Full JSON-safe dict from `output.model_dump(mode="json")`.
       - Implement `analyze(sequence: str, ctx: Any = None) -> LevelResult`:
         - Validates sequence length (25 to 1,000 residues) and standard amino acids.
         - Reports progress via `ctx.report(...)` if `ctx` is provided.
         - Runs `QuaternarySession` stages and returns `quaternary_to_level_result(session.output)`.
  </action>

  </verify>
